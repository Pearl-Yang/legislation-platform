## 🚀 使用方式

### PPTX 版（推荐答辩现场使用）

```bash
# 直接用 PowerPoint / Keynote / WPS 打开
行政立法智能辅助平台-答辩版.pptx
```

### HTML 版（推荐分享与远程答辩）

```bash
# 方式 1：直接双击 index.html 用浏览器打开
# 方式 2：本地启动（避免某些浏览器安全限制）
cd html
python -m http.server 8765
# 浏览器访问 http://localhost:8765

# 快捷键
←  → / 空格    翻页
Home / End     跳到首页/末页
1-9, 0         直接跳到第 N 页
F              全屏模式
滚轮 / 触摸滑动  翻页
```
