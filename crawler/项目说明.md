```bash

cd crawler

# 2. 安装依赖（需要Python 3.9+）
pip install -r requirements.txt

# 3. 修改数据库配置（如非默认配置）
```

### 九、常见问题解答

**Q: 爬虫是否会破坏目标网站？**
A: 已内置请求间隔（1-2秒）和并发控制，对网站压力极小。建议夜间低峰期执行。

**Q: 数据多久更新一次？**
A: 法律法规每日更新，典型案例每周更新，流程规范每月更新。可通过定时任务自动更新。

**Q: 网站改版后如何适配？**
A: 修改 `config/settings.py` 中的CSS选择器配置，无需修改核心代码。

**Q: 如何处理反爬虫？**
A: 已实现随机User-Agent、请求间隔、失败重试。如遇封IP，建议使用代理池。

**Q: 数据准确性如何保证？**
A: 建议增加人工审核流程，或实现多源数据比对。

**Q: 如何部署到服务器？**
A: 将crawler目录上传到服务器，安装依赖，配置crontab定时任务即可。
