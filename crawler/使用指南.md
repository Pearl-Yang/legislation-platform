# 青朗法治平台 - 需求调研数据爬取系统使用指南

## 一、系统概述

本系统用于从最高人民检察院官网（www.spp.gov.cn）爬取法律法规、典型案例、案件流程规范等数据，为"青朗法治智能法治平台"提供数据支撑和需求调研。

### 1.1 主要功能

- ✅ **法律法规采集**：自动爬取法律、法规、司法解释、部门规章
- ✅ **典型案例采集**：爬取刑事、民事、行政、公益诉讼等典型案例
- ✅ **流程规范采集**：采集案件生命周期各节点的规范要求
- ✅ **文书规范采集**：采集各类法律文书的格式规范
- ✅ **定时任务**：支持定时自动采集和更新
- ✅ **报告生成**：自动生成Excel和Markdown格式的需求调研报告

### 1.2 技术栈

- **语言**: Python 3.9+
- **爬虫**: requests + BeautifulSoup4
- **数据库**: MySQL 8.0
- **数据导出**: pandas + openpyxl + python-docx
- **任务调度**: schedule + threading
- **日志**: loguru

## 二、环境准备

### 2.1 Python环境

```bash
# 确认Python版本（建议3.9+）
python --version

# 如果未安装，请从 https://www.python.org/downloads/ 下载
```

### 2.2 MySQL数据库

1. 确保MySQL服务已启动
2. 创建数据库：
```sql
CREATE DATABASE IF NOT EXISTS legal_gov DEFAULT CHARSET utf8mb4;
```

3. 确保用户权限：
```sql
GRANT ALL PRIVILEGES ON legal_gov.* TO 'root'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
```

### 2.3 安装依赖

```bash
cd crawler
pip install -r requirements.txt
```

或使用国内镜像加速：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 三、快速开始

### 3.1 方式一：使用批处理脚本（推荐Windows用户）

双击运行 `run.bat`，按照提示操作：

```
1. 自动安装依赖
2. 测试数据库连接
3. 初始化数据表
4. 选择是否立即执行爬取
5. 选择是否生成报告
```

### 3.2 方式二：命令行操作

```bash
# 1. 测试数据库连接
python main.py --test-db

# 2. 初始化数据表（首次运行必须执行）
python main.py --init-db

# 3. 执行完整爬取
python main.py --crawl

# 4. 生成调研报告
python main.py --report

# 5. 启动后台定时任务（每天凌晨自动爬取）
python main.py --daemon
```

### 3.3 单任务爬取

```bash
# 只爬取法律法规
python main.py --crawl-single law

# 只爬取典型案例
python main.py --crawl-single case

# 只爬取流程规范
python main.py --crawl-single procedure

# 爬取指定URL
python main.py --crawl-single law --url https://www.spp.gov.cn/spp/law/xxx.html
```

## 四、配置说明

### 4.1 数据库配置

编辑 `config/settings.py`：

```python
class CrawlerConfig:
    DB_HOST = "localhost"        # 数据库主机
    DB_PORT = 3306               # 端口
    DB_USER = "root"             # 用户名
    DB_PASSWORD = "123456"       # 密码
    DB_NAME = "legal_gov"        # 数据库名
```

### 4.2 爬虫配置

```python
REQUEST_TIMEOUT = 30      # 请求超时时间（秒）
RETRY_TIMES = 3           # 重试次数
RETRY_DELAY = 2           # 重试间隔（秒）
BATCH_SIZE = 20           # 批量处理大小
```

### 4.3 目标网站配置

在 `config/settings.py` 的 `TARGET_SITES` 中可以配置：

- 列表页URL
- CSS选择器（用于提取标题、内容等）
- 最大爬取页数
- 爬取间隔

## 七、常见问题

### Q1: 数据库连接失败怎么办？

**A**: 检查以下几点：
1. MySQL服务是否启动
2. 数据库是否存在：`CREATE DATABASE legal_gov;`
3. 用户名密码是否正确
4. 是否授权远程连接（如果爬虫和数据库不在同一机器）

### Q2: 爬虫被反爬怎么办？

**A**: 系统已内置反反爬措施：
- 随机User-Agent
- 请求间隔
- 重试机制

如遇到封IP，建议：
1. 降低爬取频率
2. 使用代理IP
3. 在 `settings.py` 中调整 `REQUEST_TIMEOUT`

### Q3: 页面结构变化导致解析失败？

**A**: 网站改版后需要更新CSS选择器。编辑 `config/settings.py` 中的 `TARGET_SITES` 配置，调整对应的 `selectors`。

### Q4: 如何增量爬取？

**A**: 当前版本为全量爬取。如需增量，可：
1. 在表中添加 `last_update` 字段
2. 记录每个URL的最后爬取时间
3. 只爬取新增或更新的页面

### Q5: 如何停止后台定时任务？

**A**: 如果是前台运行，按 `Ctrl+C` 即可停止。如果是后台运行，查找进程并结束：
```bash
# Linux/Mac
ps aux | grep python
kill -9 <PID>

# Windows
tasklist | findstr python
taskkill /PID <PID> /F
```
