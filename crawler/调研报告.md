# 青朗法治平台 - 检察院官网需求调研报告

## 一、项目背景

本报告基于对最高人民检察院官网（www.spp.gov.cn）的系统性数据采集和分析，为"青朗法治智能法治平台"提供需求调研支撑。爬取内容包括：

1. **法律法规** - 法律、行政法规、司法解释、部门规章等
2. **典型案例** - 刑事、民事、行政、公益诉讼等各类典型案例
3. **案件流程规范** - 案件生命周期各节点的规范要求
4. **文书规范** - 各类法律文书的格式和内容要求
5. **工作规范** - 检察院内部工作流程和质量标准

## 三、平台核心功能需求

基于爬取的数据分析，平台需包含以下核心功能模块：

### 3.1 法律法规知识库模块

**功能需求**：
- ✅ **法规分类存储**：支持按法律部门、效力层级、业务领域多维度分类
- ✅ **全文检索**：支持标题、正文、关键词的模糊搜索（关键词提取已实现）
- ✅ **法条引用**：支持精确引用（如"《刑事诉讼法》第XX条"）
- ✅ **时效性管理**：自动标识法规失效��修订、废止状态
- ✅ **版本对比**：支持不同版本间的差异对比
- ✅ **知识图谱**：构建法规、案例、流程的关联关系（可选，二期）

**数据字段**：
```python
法规 = {
    '标题': '中华人民共和国刑事诉讼法',
    '类型': '法律',
    '发布部门': '全国人民代表大会',
    '发布日期': '2018-10-26',
    '生效日期': '2018-10-26',
    '文号': '',
    '全文内容': '...',
    '分类': '刑事诉讼',
    '关键词': '刑事,诉讼,程序,检察,法院',
```

**存储表设计**：`legal_regulation`

### 3.2 典型案例库模块

**功能需求**：
- ✅ **案例分类管理**：按案由、罪名、审理法院、年份等多维度分类
- ✅ **案例检索**：全文检索 + 高级检索（案由、法院、时间段）
- ✅ **类案推送**：基于案由相似度智能推送相关案例
- ✅ **案例详情**：展示基本信息、案情、裁判理由、结果、法律依据
- ✅ **案例评析**：自动提取案例要点、亮点、典型意义
- ✅ **案例对比**：支持多案例横向对比分析

## 五、技术实现方案

### 5.1 Python爬虫系统

**技术栈**：
- 请求库：requests + httpx
- 解析库：BeautifulSoup4 + lxml
- 数据存储：pymysql + SQLAlchemy
- 报告生成：pandas + openpyxl + python-docx
- 任务调度：schedule + apscheduler
- 日志：loguru

**核心功能**：
1. **多站点爬取**：支持法律、案例、规范多栏目
2. **智能解析**：自适应不同页面结构
3. **去重机制**：基于标题、编号去重
4. **错误重试**：网络异常自动重试
5. **礼貌爬取**：请求间隔 + User-Agent轮换
6. **定时任务**：支持定时自动爬取
7. **报告生成**：自动生成多维度分析报告

### 5.2 Spring Boot集成方案

**技术栈**：
- 框架：Spring Boot 3.2.5 + MyBatis Plus
- 数据库：MySQL 8.0 + Neo4j
- 任务调度：Quartz
- 缓存：Redis

**集成方式**：
1. 爬虫数据直接写入MySQL爬虫表
2. 提供REST API供前端调用
3. 后台定时任务（Quartz）调用Python爬虫或Java爬虫
4. 数据同步到Neo4j知识图谱（可选）

**API接口设计**（建议）：
```
GET  /api/crawl/regulations          # 获取法规列表
GET  /api/crawl/regulations/{id}     # 获取法规详情
GET  /api/crawl/cases                # 获取案例列表
GET  /api/crawl/procedures           # 获取流程节点
GET  /api/crawl/documents            # 获取文书规范
POST /api/crawl/trigger              # 手动触发爬取
GET  /api/crawl/report               # 生成并下载报告
```

### 5.3 数据库表设计

已创建完整的8张爬虫数据表，详见 `government_edition/backend/sql/crawl_data_schema.sql`
