# 智立法小程序

基于 uni-app / Vue 3，包含登录、工作台、八个业务模块及个人中心。使用蓝色主题和共用组件：页头、统计卡片、模块入口、筛选、搜索、加载/空数据/错误状态、底部弹层与流程条。

## 本地预览

在本目录执行：

```powershell
npm ci
npm run dev:h5
```

打开 http://localhost:3004 。后端需要运行在 http://localhost:8083/api ，可用 `admin / 123456` 登录本地测试数据库。Web 管理端仍使用 3003 端口。

小程序请求使用真实 Bearer token。错误密码或后端不可用时会保留错误提示；不会自动进入假登录状态。服务地址可在登录页或个人中心的「连接设置」中修改，也可通过 `VITE_API_BASE_URL` 指定。

## 微信开发者工具

```powershell
npm run build:mp-weixin
```

将 `dist/build/mp-weixin` 导入微信开发者工具。本地编译产物使用游客 AppID；正式关联小程序时，在 `src/manifest.json` 的 `mp-weixin.appid` 配置实际 AppID。真机调试时，连接设置需填写电脑的局域网地址（例如 `http://192.168.1.10:8083/api`），并确保后端可从该网络访问。

## 使用与边界

- 项目列表支持类型/状态筛选、搜索已加载项目、加载更多及详情查看。
- 资料库支持关键词检索、类型筛选、收藏列表、正文和批注。
- 公开征集支持详情查看、公众意见填写和发布表单。发布前校验标题、起止日期；提交中阻止重复点击。
- 审查首页展示规则库。真实审查结果从草案提交审查后查看，不把规则列表当作已发现的问题。
- 统计与列表读取实际接口。加载失败提供重试，成功但没有记录时展示空状态；不会用演示统计掩盖接口错误。
- 后端 API 的功能与权限决定具体操作能否完成；本次不调整后端服务。

## 验证

```powershell
npm test
npm run build:mp-weixin
npm run build:h5
```

回归测试覆盖后端扁平登录响应、真实身份保存、退出清理、请求 token、过期登录、网络错误、地址校验、快速搜索竞态及重试。浏览器验证使用实际后端登录，并以隔离测试数据检查列表、搜索和表单；测试数据不会写入业务数据库。H5 预览用于页面与交互检查，不替代微信真机验证。
