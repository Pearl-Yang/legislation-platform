## Slide 2:背景(1.5 分钟)

**讲**:截至 2024 年底,我国共有 **5 部法律 + 30 部行政法规 + 8000 部地方规章**;每年新增地方规章 800+ 部。立法流程普遍存在 3 个问题:

1. **效率低** — 从立项到公布平均 18 个月,流程节点 10+ 个
2. **风险高** — 越权立法、引用上位法冲突、引用失效法条等人工难以穷尽
3. **参与弱** — 公众意见分散于网站、APP、座谈会、纸质件,难以归类统计

我们的目标:把 18 个月压到 **9-12 个月**,把风险检查 **人工→AI 自动化**,把意见处理 **碎片化→结构化**。

---

## Slide 3:架构图(2 分钟)

**讲**:整体架构分 4 层:

- **接入层**:Web 前端(Vue 3 + Element Plus) + 微信小程序 + 公开 H5 页面
- **应用层**:Spring Boot 3.1 + 14 个 Controller + 9 个 Service + Qwen AI
- **数据层**:MySQL 24 张表 + Neo4j 关系图谱(可选) + Redis 缓存 + 5 个种子用户 BCrypt
- **可观测**:Prometheus 抓取 + Grafana 大盘 + ELK 风格 JSON 日志

技术亮点:
- **Jwt 鉴权 + Spring Security**
- **@Async + ThreadPoolTaskExecutor** 异步任务框架
- **@RestControllerAdvice** 全局异常处理
- **JPA-style MyBatis-Plus** ORM + 自动分页
- **SpringDoc + Knife4j** OpenAPI 文档
- **Qwen 在线/离线双通道**(LLM 容错)

## Slide 5:演示-项目流程端到端(3 分钟)

**讲**:我用 admin / 123456 登录,创建一个新项目"XX 智慧城市管理条例"。我们看到项目立项后**自动初始化 10 个流程节点**(立項建議 → 立项审查 → 起草 → 征求意见 → 专家论证 → 风险评估 → 法制审查 → 审议 → 公布 → 备案)。推进到下一阶段自动写入操作时间和操作人。

**点击进入详情页**:
- 顶部新增 **7 天预警徽章**(自动根据期限计算)
- 项目基本信息卡片(项目类型、当前节点、整体进度条 55%)
- **ECharts 流程图**(本日新增):把 10 个阶段渲染成图形,当前阶段用蓝色高亮 + 阴影,已完成绿色,待办灰色
- **流程节点明细**:竖直步骤条 + 每节点有法定期限、开始/完成时间、备注

**操作**:
- 点击「推进下一阶段」按钮 → 自动推到下个节点 → 大屏进度从 55% → 66%
- 点击「回退」按钮 → 输入目标阶段序号 5 → 回退到专家论证

**讲点**:**这是完整的"流程可视化 + 端到端推进"**,基于《行政法规制定程序条例》配置模板。

## Slide 6:演示-草案生成(2 分钟)

**讲**:基于当前项目类型 + 当前节点,自动加载上位法条款和异地参考规章,**异步生成草案**。

**操作**:
1. 点击「前往生成」按钮
2. 选择项目、填入上位法条款(如《数据安全法》第 21 条)、细化事项
3. 点「开始生成」→ 拿到 taskId,**异步任务框架**(@Async + ThreadPoolTaskExecutor)后台跑
4. 前端 1.5 秒轮询 `/commit/task/{taskId}` 直到 SUCCESS
5. 显示生成的 6 章 Markdown 草案正文,含参考片段、提示词快照
6. 点击「导出 Markdown / Word」

**讲点**:**AI 生成 + 异步任务 + 轮询 + 版本快照 + 导出**,完整链路。

## Slide 7:演示-智慧审查(2 分钟)

**讲**:对生成的草案触发审查,内置 **6 类规则**:
- **上位法冲突**(红色严重)
- **违规越权**(红色严重)
- **引用失效法条**(黄色关注)
- **条文重复**(黄色关注)
- **格式不规范**(蓝色格式)
- **言语文繁杂**(灰色优化)

**操作**:选草案 → 选启用规则(默认全启用) → 点「开始审查」→ 1 秒返回审查记录 → 显示 4 级问题统计卡 + 问题列表 + 每条可「标记解决」

**讲点**:**规则引擎 + 4 级问题分类 + 批审查 + 决议追溯**。

## Slide 8:演示-清理 + 评估(3 分钟)

**讲**:**清理任务**(模块 4):支持 DAILY / PERIODIC / THEMATIC 三种触发模式。创建「2026Q4 规章集中清理」任务,系统推荐 124 个候选法规,AI 给每个候选 KEEP / MODIFY / OBSOLETE 建议及置信度,可手工决策最终去向。

**讲点**:**清理启发式打分 + 评估三维指标 + 雷达图可视化**。

## Slide 12:AI 能力(1.5 分钟)

**讲**:我们封装了 Qwen 在线/离线双通道 `QwenFacade`:

```java
String content = qwenFacade.execute(
    userPrompt,
    () -> buildPlaceholderContent(...)  // 离线兜底
);
```

- 在线模式:配 `legislation.qwen.mode=online` + API Key,真 LLM 生成
- 离线模式:模板拼接 + 占位章节,跑通业务链路
- **降级机制**:在线调用失败 → 自动降级到离线,前端仍能演示

**AI 应用 4 场景**:
- 草案生成(模板占位 + RAG 预留)
- 智慧审查(6 类规则 + 关键词命中)
- 清理建议(置信度评分)
- 意见归类(SimHash + 立场识别)

**讲点**:**框架就绪 + 双通道 + 降级机制**。
